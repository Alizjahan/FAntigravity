# مستندات FAntigravity (RTL)

ابزار FAntigravity جهت افزودن قابلیت‌های راست‌به‌چپ (RTL)، شخصی‌سازی تایپوگرافی فارسی و مدیریت تم به نرم‌افزار Antigravity طراحی و توسعه یافته است.

## قابلیت‌ها

- سیستم سه‌حالته انتخاب تم:
  - تم روشن (Light Mode)
  - تم تاریک (Dark Mode)
  - تم ستاره (Antigravity Star Mode) با طیف رنگی اختصاصی
- رابط کاربری به زبان فارسی هماهنگ با طراحی مدرن
- پشتیبانی از فونت‌های فارسی:
  - فونت متغیر وزیرمتن (Vazirmatn Variable) تعبیه‌شده آفلاین
  - فونت وب اسنپ (Snapp Web)
  - قابلیت تعیین فونت دلخواه نصب‌شده در سیستم
- تنظیم اندازه قلم و فاصله بین خطوط با دکمه بازنشانی به مقادیر پیش‌فرض
- عملکرد کاملاً آفلاین بدون ارسال داده یا وابستگی به شبکه خارجی
- اصلاح خودکار کلید Shift + 2 برای درج علامت @ در صفحه‌کلید فارسی

## روش‌های نصب و راه‌اندازی

### روش اول: اجرای مستقیم از طریق NPX (پیشنهادی)
```bash
npx fantigravity-rtl
```

### روش دوم: اجرای اسکریپت دسته‌ای (Windows Batch)
فایل `install.bat` را اجرا نمایید. برنامه به صورت خودکار مسیر نصب نرم‌افزار را شناسایی کرده و پچ را اعمال می‌کند.

### روش سوم: اجرا از طریق سورس پروژه
```bash
git clone https://github.com/Alizjahan/FAntigravity.git
cd FAntigravity
npm install
node bin/index.js
```

---

## بازگردانی به نسخه اولیه (Restore)

جهت لغو تغییرات و بازگردانی فایل‌های اصلی برنامه:

```bash
npx fantigravity-rtl --restore
```
یا فایل `restore.bat` را در ویندوز اجرا نمایید.

---

## ساختار فایل‌ها

- `bin/`: هسته منطق پچ، رابط کاربری پنل و فونت‌های تعبیه‌شده
- `header.jpg`: تصویر بنر اصلی مخزن
- `custom-icon.png`: نشان گرافیکی اختصاصی برنامه
- `install.bat`: اسکریپت نصب خودکار در ویندوز
- `restore.bat`: اسکریپت بازگردانی نسخه پشتیبان
- `package.json`: پیکربندی بسته و تعاریف دستورات اجرایی
