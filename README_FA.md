# مستندات FAntigravity (RTL)

ابزار FAntigravity جهت افزودن قابلیت‌های پیشرفته راست‌به‌چپ (RTL)، شخصی‌سازی تایپوگرافی فارسی و مدیریت تم به صورت اختصاصی برای نرم‌افزار مستقل Google Antigravity توسعه یافته است.

---

## قابلیت‌ها

- سیستم سه‌حالته انتخاب تم:
  - تم روشن (Light Mode)
  - تم تاریک (Dark Mode)
  - تم ستاره آنتی‌گرویتی (Antigravity Star Mode) با طیف رنگی اختصاصی
- رابط کاربری به زبان فارسی هماهنگ با طراحی مدرن
- پشتیبانی از فونت‌های فارسی:
  - فونت متغیر وزیرمتن (Vazirmatn Variable) تعبیه‌شده آفلاین
  - فونت وب اسنپ (Snapp Web)
  - قابلیت تعیین فونت دلخواه نصب‌شده در سیستم
- تنظیم اندازه قلم و فاصله بین خطوط با دکمه بازنشانی به مقادیر پیش‌فرض
- عملکرد کاملاً آفلاین بدون ارسال داده یا وابستگی به شبکه خارجی
- اصلاح خودکار کلید Shift + 2 برای درج علامت @ در صفحه‌کلید فارسی
- پشتیبان‌گیری خودکار از فایل اصلی پیش از اعمال هرگونه تغییر

---

## توجه درباره Antigravity IDE

این پروژه منحصراً برای اپلیکیشن مستقل Antigravity توسعه یافته است. برای محیط **Antigravity IDE** (نسخه مبتنی بر VS Code)، افزونه رسمی و مجزا به زودی جهت نصب آسان از طریق بخش افزونه‌ها (Extensions Marketplace) منتشر خواهد شد.

---

## روش‌های نصب و راه‌اندازی

### روش اول: اجرای مستقیم از طریق NPX (پیشنهادی)

در محیط خط فرمان (PowerShell در ویندوز یا Terminal در مک و لینوکس):

```bash
npx -y -p github:Alizjahan/FAntigravity fantigravity
```

### روش دوم: اجرای اسکریپت دسته‌ای (Windows Batch)

فایل `install.bat` را اجرا نمایید. برنامه به صورت خودکار مسیر نصب نرم‌افزار را شناسایی کرده و پچ را اعمال می‌کند.

### روش سوم: اجرا از طریق سورس پروژه

```bash
git clone https://github.com/Alizjahan/FAntigravity.git
cd FAntigravity
npm install
node bin/index.js
```

---

## بازگردانی به نسخه اولیه (Restore)

جهت لغو تغییرات و بازگردانی فایل اصلی برنامه با استفاده از فایل پشتیبان:

```bash
npx -y -p github:Alizjahan/FAntigravity fantigravity --restore
```

یا اجرای فایل `restore.bat` در محیط ویندوز.

---

## ساختار فایل‌ها

- `bin/`: هسته پچ برنامه، منطق تزریق و فونت‌های تعبیه‌شده
- `header.jpg`: تصویر بنر اصلی مخزن
- `install.bat`: اسکریپت اجرای سریع در ویندوز
- `restore.bat`: اسکریپت بازگردانی نسخه پشتیبان در ویندوز
- `package.json`: پیکربندی بسته و تعاریف دستورات اجرایی
